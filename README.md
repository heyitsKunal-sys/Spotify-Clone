🎵 Spotify Clone

A fully responsive Spotify Clone built using HTML, CSS, and JavaScript.
This project recreates the modern Spotify UI with music controls, playlists, animations, and responsive design.

🚀 Features
🎧 Modern Spotify-inspired UI
📱 Fully Responsive Design
▶️ Play / Pause Music
⏭️ Next & Previous Song Controls
🎵 Dynamic Song List
📀 Rotating Album Animation
🔊 Volume Control
📊 Progress Bar / Seek Bar
🌙 Smooth Hover Effects & Transitions
⚡ Fast and Lightweight

🛠️ Tech Stack
HTML5
CSS3
JavaScript (Vanilla JS)

📂 Project Structure
spotify-clone/
│── index.html

│── script.js

🎮 How to Run the Project
1.Clone the repository
git clone https://github.com/your-username/spotify-clone.git

2.Open the project folder
cd spotify-clone

3.Run the project
Open index.html in your browser
